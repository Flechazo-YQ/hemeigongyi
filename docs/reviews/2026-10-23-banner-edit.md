# 往期活动编辑与公众号跳转

日期：2026-10-23。AppID：`wx8eba34c3c73d6550`。目标环境：`cloud1-0gmvnn0id639de25`。隔离发布基线：`1c6aafe`。最终开发版版本：`20261023.4`。

## 已实现

- 活动卡片原来只有删除；现在右下方并排显示“编辑 / 删除”横向按钮。
- 编辑复用原表单，自动带入图片、标题、副标题、角标、链接；支持补填和清空跳转链接。
- 只改文字或链接不重新上传图片，也不把云存储的临时签名网址写回数据库；活动 ID、创建时间、列表顺序和其他字段保留。
- 保存中防止重复提交及误关闭；后端业务失败保留输入。修改后关闭弹窗提供保存、放弃、继续编辑；原生返回启用离开提醒，未声称覆盖系统手势的全部情况。
- 公众号完整文章链接调用 `wx.openOfficialAccountArticle({url})`；失败或旧微信不支持时保留复制引导。链接输入长度放宽至 8192，防止默认长度截断公众号参数。
- `manageBanners` 新增 `update`，使用平台 OPENID 核实 admin/publisher 权限，只更新允许的展示字段并检查实际更新结果。
- 同值保存返回更新 0 条时进一步检查记录是否存在，存在则成功，避免将未修改误判成活动失效。
- 系统固定内容沿用已有固定展示规则。

微信接口依据：[腾讯官方 API 类型与说明](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)，参数为 `url`；已发布文章需要真实点击触发，临时预览文章不在其支持范围。
