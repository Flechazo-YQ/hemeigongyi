# 任务 06：AI 研学前端复用既有云函数

- 将 `pages/ai-research/ai-research.js` 的供应商直连改为 `wx.cloud.callFunction({ name: 'getAIChat', data: { messages } })`，沿用已配置的后端，不修改服务端模型、凭证或供应商配置。
- 删除前端硬编码认证、供应商地址、模型标识和 SSE 分块解码。前端按既有云函数合同读取完整回复，保留研学规划师提示、欢迎语打字效果和滚动行为。
- 请求中显示“正在思考，请稍候…”，防止重复提交；成功替换占位消息；云端业务失败（包括后端 HTTP 错误）、网络失败、超时及空回复均有明确中文反馈，并释放 loading 状态。错误反馈不展示后端 `error`、`details` 或原始异常。
- 离开页面时清理欢迎语和滚动定时器，使进行中的响应失效。云函数 SDK 的 Promise 无中止接口，此处取消的是页面接收与更新，不宣称终止服务端执行。
- 用户当次指令要求直接实现代码，凭证轮换不涉及；报告不记录凭证值。既有后端供应商无需用户登录或额外操作。
